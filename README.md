# 🔥 PowerForge

**PowerForge** is a modern, responsive fitness and gym web application built with React.  
It focuses on strength, discipline, and performance — helping users **forge real power** through a bold UI and clean user experience.

## 📦 Installation & Setup

Follow these steps to get PowerForge running locally:

```bash
Clone the Repository
git clone https://github.com/your-username/powerforge.git

Navigate to the Project Directory
cd powerforge

Install Dependencies
npm install

Run the Development Server (Vite)
npm run dev

Run the Development Server (Create React App)
npm start

Build for Production
npm run build

Preview Production Build (Vite)
npm run preview

```
